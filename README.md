## Jordan McKenzie

Transport Canada Advanced RPAS Pilot and Flight Reviewer · B.Sc. Computer Science ·
Greater Toronto Area, Ontario

I fly drone surveys and write the Python that turns the raw data into something a client can
trust. My work covers UAV LiDAR and magnetometer surveys on long range BVLOS crews,
photogrammetry and LiDAR processing, and automated QA before anything is delivered. I have
worked with geospatial software since 2019.

### Projects

| Project | What it shows |
|---|---|
| [Flight Log Analyzer](https://github.com/jjmmcckk/flight-log-analyzer) | Flight test reports from ArduPilot logs: attitude step response, QuadPlane transitions, before and after AUTOTUNE, and health checks against a test card. Demonstrated on a QuadPlane test card flown in ArduPilot SITL. |
| [LiDAR Web Map](https://github.com/jjmmcckk/lidar-web-map) · [live demo](https://jjmmcckk.github.io/lidar-web-map/) | One LiDAR file turned into web layers that stream from static hosting: the point cloud as OGC 3D Tiles, bare earth and surface models as Cloud Optimized GeoTIFFs, and contours and QA results as PMTiles vector tiles, in a React, TypeScript, MapLibre and deck.gl viewer. |
| [Multispectral Pipeline](https://github.com/jjmmcckk/multispectral-pipeline) | Vegetation and water analysis from multispectral imagery: every date aligned to one grid, NDVI, GNDVI, NDWI, NDRE and SAVI computed block by block, vegetation classes, change between dates and management zones, with an HTML report. Shown on ten years of public NAIP imagery. Tested in CI. |
| [LiDAR QA Toolkit](https://github.com/jjmmcckk/lidar-qa-toolkit) | One command QA for LAS/LAZ point clouds: density against a target, coverage of the planned survey area, void and low density polygons, classification and noise, with an HTML report and GIS outputs. Tested in CI. |
| [Geospatial AI Labs](https://github.com/jjmmcckk/Geospatial-AI-Labs) | Four graduate geospatial machine learning projects, run end to end with baselines: 93.3% aerial image classification with transfer learning, a Space2Vec location encoder that cuts error 20%, LSTM rainfall forecasting and spatial regression. |
